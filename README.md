## GitHub Pages 发布

1. 将本目录内容上传到 `Alec-Courtney/portrait-atelier` 仓库的 `main` 分支。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，选择 `main` 和 `/(root)`，保存。
4. 等待 Pages 构建成功后，使用设置页显示的网址。

所有资源均使用相对路径，支持 GitHub Pages 项目子路径，无需安装依赖或构建。

Pages 通常公开可访问。保留的 `noindex` 仅请求搜索引擎不收录，并不限制访问。

此副本仅包含当前展示的照片和网页文件，不包含已撤下版本、参考照片或生成提示词。
